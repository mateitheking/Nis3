# Nis3

Единый кабинет НИШ — расписание, оценки и AI-ассистент поверх СУШ и EduPage.

Ученики НИШ держат учебную информацию в двух несвязанных системах: EduPage
(расписание, СОР/СОЧ, консультации, уведомления) и СУШ (оценки). Nis3
собирает их в один кабинет и добавляет то, чего нет ни там, ни там —
калькулятор нужного балла за СОЧ, разбор слабых тем и AI-ассистента,
который отвечает на вопросы по твоим собственным данным.

## Что внутри

- **Расписание** — неделя и день, свои записи (репетиторы, кружки), бейджи
  СОР/СОЧ/БЖБ прямо в сетке
- **Оценки** — по четвертям и годам, разбивка по темам, калькулятор «сколько
  нужно за СОЧ» и разбор самых слабых тем
- **Файлы** и **Уведомления** — фото ученика и единая лента событий EduPage
- **NisAI** — ассистент с доступом к твоему расписанию и оценкам через
  function calling, а не выдуманные цифры

## Стек

Backend: Python 3.12 + FastAPI + SQLite.
Frontend: React + Vite + TypeScript.
